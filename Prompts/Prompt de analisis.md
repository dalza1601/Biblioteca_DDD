# Rol Agente

Actua como arquitecto DDD.

# Caso

Una biblioteca educativa registra ejemplares y administra prestamos a estudiantes. La oficina de catalogos crea y
desactiva libros. La oficina de Prestamos registra la entrega y devolucion de un ejemplar.

# Indicaciones

- Indentifica los bounded context y que responsabilidad tiene cada uno.
- Explica por que prestamos no deberia cambiar el titulo de un libro.
- Clasifica Libro, Prestamo, CodigoLibro y CodigoLector como entidad, root Aggregate o Value Object,
  justificando con el criterio de identidad vs valor.
- Indica que dato es lo unico que prestamos conserva de un libro.

# Entregables

- Responde con una tabla corta, no generes codigo y se breve con tu reporte de analisis.
